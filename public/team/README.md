# Team photographs

Drop headshots here using the filenames declared in `src/data/team.ts`:

    tarun-shah.jpg
    mayur-fichadiya.jpg
    mansi.jpg
    hemal-shah.jpg
    ...

Square or 3:4 portrait crops, 800px on the short edge or larger.

Any file that is absent falls back to a monogram panel automatically, so
the layout is complete whether or not the photography has arrived.
